Text targets

When a text step runs, PointRunner first searches the active window's accessibility tree (including browser page text such as “Slow download”), then falls back to Windows OCR on the full virtual screen. Keep the target window in the foreground. Leave Text blank to click the saved X/Y coordinate.

Point delays may be set to 0 ms; newly added points use zero delays.
